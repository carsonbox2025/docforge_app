# DocForge App 增强任务计划

## 概述

### 阶段一：纯前端快速修复（P0）
1. 任务3：历史文档路由修复

3. 任务2：底部导航统一圆形样式
4. 任务5：关于稿搭子页面
5. 任务6：注册页隐私协议

### 阶段二：后端 API 开发
6. 任务8 后端：用量统计 API（扩展 QuotaService）

8. 任务7 后端：用户反馈 API（新建表+路由+服务）
